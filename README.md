# Operations Research & Optimization

Mathematical optimization and operations-research projects — vehicle routing, the travelling-salesman problem, and linear programming. The focus is on modelling a real problem formally, then solving it efficiently.

## Projects

### `vehicle_routing_ademe.ipynb`
A Vehicle Routing Problem framed for the French Agency for Ecological Transition (ADEME). Includes the formal graph formulation, mathematical definition of the problem, and a solver built with `pyvrp`. Academic group project (Algorithms & Combinatorial Optimization), fully documented from problem statement to results.

### `tsp_solver_numba.ipynb`
A Travelling Salesman Problem solver with performance-critical routines accelerated using Numba JIT compilation — a study in making an optimization routine fast, not just correct.

### `linear_programming_pulp.ipynb`
Linear programming with PuLP: modelling and solving an operations-research problem, with interactive parameter exploration. Academic workshop built on a provided scaffold; the modelling and solution work are my own.

## Stack
Python · pyvrp · PuLP · Numba · NumPy · Matplotlib

## Notes
Developed in Google Colab. Mathematical formulations are written up inline in each notebook.
